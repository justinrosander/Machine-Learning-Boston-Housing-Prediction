# EDA Project Structure

This repository is scaffolded for a minimal exploratory data analysis workflow.

## Folders

- `data/raw/` — original, immutable datasets
- `data/interim/` — temporary cleaned/merged datasets
- `data/processed/` — final analysis-ready datasets
- `notebooks/` — Jupyter notebooks for exploration
- `src/` — reusable Python helper code
- `reports/` — written outputs and summaries
- `reports/figures/` — plots and charts used in reports

## Quick Start

1. Put source files in `data/raw/`
2. Create your first notebook in `notebooks/`
3. Save reusable functions in `src/`
4. Export final visuals to `reports/figures/`
